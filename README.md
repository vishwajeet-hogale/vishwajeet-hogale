## 🛠️ Featured Projects

| Project | What it is |
|---|---|
| [GymDriveVLA](https://github.com/vishwajeet-hogale/GymDriveVLA) | A small vision-language-action model that learns to drive in the CarRacing Gym simulator from "go slow" and "go fast" instructions |
| [Tiny-VLA](https://github.com/vishwajeet-hogale/Tiny-VLA) | Diffusion Policy and ACT imitation policies trained on PushT with LeRobot, compared across seeds and failure modes |
| [Multi-Modal 4DoF 3D Object Detection](https://github.com/vishwajeet-hogale/Hybrid-Scene-Encoder-For-Agent-Detection) | A BEV encoder fusing LiDAR (PointPillars) and camera features for 3D object detection on nuScenes |
| [Transformers From Scratch](https://github.com/vishwajeet-hogale/Transformers-From-Scratch) | ViT and a simplified DETR built from scratch in PyTorch, trained on CPPE-5 |
| [Vision-Language Damage Segmentation](https://github.com/99anjalipai/Segment-Damage) | YOLOv8, U-Net and Mask2Former segmentation with a VLM grounded on the damaged regions (team project) |
